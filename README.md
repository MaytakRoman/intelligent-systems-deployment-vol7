# Инженерная практика развёртывания интеллектуальных систем — том 7

Электронное приложение к книге П. А. Пылова, Р. В. Майтака, А. В. Протодьяконова. Версия приложения **1.0.0**, 16.10.2026.

Репозиторий: https://github.com/MaytakRoman/intelligent-systems-deployment-vol7

## Быстрый запуск

Требуется **Python 3.9 или новее**. Расчётные программы используют стандартную библиотеку; `pip install` не требуется. Перейдите в корень распакованного проекта:

```bash
python3 programs/reproduce.py
python3 -m unittest discover -s tests -v
```

В Windows вместо `python3` можно использовать `py -3`. Путь к проекту может содержать кириллицу. Результаты нового запуска появляются в `lab_results/`; они сравниваются с `control_results/summary.json`. Запуск не обращается к сети и не развёртывает сервис.

При 2 млн изделий в месяц: автоматических своевременных решений — 1 630 368; оставшаяся обработка — 369 632; расход нового процесса — 1 087 224 руб.; эффект — 412 776 руб./мес. При своевременности 99,5 % эффект равен 407 880 руб./мес.; это сценарий нарушения SLO. ## Границы применения

Все исходные данные и результаты учебные. `model.bin` — текстовый контрольный объект, **не обученная модель**. Его байты и контрольные суммы согласованы с двумя манифестами книги. `acceptance.json` явно запрещает трактовать комплект как промышленно принятый. Проверка SHA-256 не является электронной подписью и не устанавливает происхождение либо качество модели.

Симуляция предполагает одинаковое детерминированное время обслуживания и не включает сеть, подтверждение внешнего действия или случайные отказы. Она воспроизводит отдельный расчёт, а не сертифицирует SLO всей системы.

YAML — учебный шаблон. Нулевой дайджест образа необходимо заменить реальным; готового образа в приложении нет. Перед применением подтверждают поддержку `minDomains`, наличие отдельных узлов и дополнительного места для обновления, а также реализацию `/ready`, `/alive` и корректного завершения в самом сервисе. PDB ограничивает добровольные выселения; аппаратные отказы и обновление Deployment имеют другие механизмы.

Матрица требований — шаблон для заполнения по официальным действующим источникам; строки не означают проведённую юридическую экспертизу. Лицензия MIT распространяется только на код и шаблоны приложения. Права на текст книги определяются отдельно.

## Загрузка на GitHub

Распакуйте ZIP. Загрузите **содержимое** распакованной папки в корень этого репозитория с сохранением `programs`, `data`, `examples`, `deployment`, `templates`, `docs`, `tests`, `control_results`, `lab_results`. Замените одноимённые файлы. ZIP можно дополнительно приложить к релизу `v1.0.0`; для работы ссылок из книги необходимы распакованные файлы на ветке `main`.
